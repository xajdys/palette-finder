A simple, interactive web application for exploring color palettes, copying color codes, and saving favorite combinations.

Palette Finder helps you discover colors for your next web development project. Search palettes by name, filter them by mood, and keep track of the combinations you love.

## ✨ Features

- **🔍 Live Search** — Find palettes by name as you type.
- **🎭 Mood Filtering** — Filter palettes by mood, including Warm, Cool, Calm, and Bold.
- **🔀 Combined Filtering** — Combine search and mood filters to find matching palettes.
- **📋 Copy Color Codes** — Copy all the hex codes from a palette with one click.
- **⭐ Favorite Palettes** — Mark palettes as favorites and remove them whenever you like.
- **💾 Persistent Favorites** — Keep your favorite palettes saved across page reloads using `localStorage`.
- **🚫 No-Results Feedback** — Get a message when no palettes match your search or selected mood.

## 🛠️ Built With

- HTML5
- CSS3
- JavaScript (Vanilla JS)
- Browser `localStorage` API

No JavaScript frameworks or external libraries are required for the core functionality.

## 🚀 Getting Started

### Run Locally

1. Clone this repository:

   ```bash
   git clone <repository-url>
   ```

2. Navigate into the project folder:

   ```bash
   cd palette-finder
   ```

3. Open `index.html` in your browser.

   Alternatively, open the project in VS Code and use the Live Server extension.

## 📖 How to Use

1. Browse the available color palettes.
2. Enter a palette name in the search field to find matching palettes.
3. Select a mood to narrow down the results.
4. Click **Copy colors** to copy a palette's hex codes.
5. Click **Favorite** to save a palette to your favorites.
6. Reload the page to see your saved favorites restored.
